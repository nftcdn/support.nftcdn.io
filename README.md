# NFTCDN Support Repository

You can open here issues when using https://nftcdn.io.
See the [official documentation](https://nftcdn.io/doc).

If you prefer, you can get live support in [NFTCDN Discord](https://discord.nftcdn.io) `#support` channel or ask for a private support channel there.

This repository also contains code samples to authenticate NFTCDN URLs, see [authentication code documentation](https://nftcdn.io/doc#authentication-code-tk-token-parameter).

These examples are not intended to be canonical implementations per language. This is not a library. These are simply minimal examples avoiding third-party libraries and as close to each other as possible, in order to facilitate understanding of the implementation of HMAC code authentication.
